# Wearly 👗

An image-based clothing search project that helps users find visually similar fashion items within a chosen budget.

## How it works

1. The user provides a clothing image and a maximum price.
2. The model converts the image into an embedding.
3. The search compares it with precomputed catalog embeddings.
4. Products within the budget are ranked by visual similarity.

## Features

- Image-based product search
- Maximum-price filtering
- Results ranked by visual similarity
- Product information and shopping links

## Technologies

- Python
- PyTorch
- pandas
- FashionCLIP
- Google Colab
